Features

6 modules · 1 account
F01email

Email on your domain

Addresses on a domain you own, with sending, receiving, aliases and catch-all.

  • hello@, support@, sales@ in one click
  • IMAP, SMTP and JMAP
  • Shared inboxes per address
F02dns

DNS that verifies itself

Records are written through Domain Connect where supported and checked automatically.

  • Cloudflare, GoDaddy, IONOS
  • Manual copy with live status
  • Send records to a developer
F03agents

Agents with scoped access

Connect an agent over MCP. Each gets its own token and only the permissions you tick.

  • Read, draft, send, label
  • Per-agent audit log
  • Revoke in one click
F04data

Data you can query

Mail, contacts and files are indexed into tables you and your agents can read.

  • SQL and JSON endpoints
  • Full-text search
  • Daily snapshots
F05sites

Sites on the same domain

Publish static pages and forms at your root or any subdomain, no extra host.

  • Deploy from git or upload
  • Forms land in your inbox
  • Edge cache, free TLS
F06api

Human and machine readable

Every public page serves HTML to people and JSON, Markdown or llms.txt to programs.

  • Content negotiation on every URL
  • OpenAPI and MCP manifests
  • Structured data on every page

Questions

Also answered at /faq.json and in the page's structured data.

Do I need to own a domain?+−

No. Connect one you own, buy one during setup, or start on a free you.xstate.email subdomain and move later.

Which agents can read my mail?+−

Claude, Claude Code, Codex and Cursor connect over MCP. Each agent gets its own scoped token; you choose read, draft, send and label permissions.

How long does DNS take?+−

With Domain Connect (Cloudflare, GoDaddy, IONOS) records are written for you and verify in under a minute. Manual records usually verify within 15 minutes.

Can I export everything?+−

Yes. Mail as .mbox, data as JSON or CSV, sites as static files. Exports are available on every plan.

What does machine readable mean here?+−

Every public URL returns HTML by default and JSON or Markdown when asked via the Accept header. The site also publishes llms.txt, an OpenAPI document, an MCP manifest and schema.org data in each page.
